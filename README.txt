NILI'S KITCHEN AI

INSTALL:

1) Open terminal

2) Go project folder

3) Run:

npm install

4) Create .env file

5) Add:

OPENAI_API_KEY=your_key
SPOON_KEY=your_key
PORT=3000

6) Start:

node server.js

7) Open browser:

http://localhost:3000
